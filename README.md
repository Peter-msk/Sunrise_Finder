# Sunrise Finder

**현재 제품 메타데이터 기준: v2.1.2** · Windows 10/11 x64 · 폴더형 실행 프로그램(onedir)

주소·좌표·지도·공공데이터·현장사진·공간분석 정보를 하나의 프로젝트에서 관리하는 Sunrise Group의 현장조사 및 GIS 업무지원 도구입니다.

## 1. 프로그램 개요
Sunrise Finder는 환경영향평가, 현장조사, 시설물 조사 및 사업구간 검토에 필요한 위치정보를 검색하고 지도에서 확인하며 결과를 프로젝트 단위로 정리합니다.

## 2. 개발 목적
- 주소와 좌표를 검색·변환하여 조사 위치를 확인합니다.
- 현장조사지점과 사진·메모·이동 경로를 연결해 관리합니다.
- 건축·지도·공간 공공데이터를 조사 대상 위치와 함께 확인합니다.
- 사용자 GIS 자료와 사업구간을 이용한 공간분석을 지원합니다.
- 프로젝트를 저장하고 이후 작업을 이어갈 수 있도록 합니다.

## 3. 주요 기능
- 도로명주소·지번주소 검색, 주소↔좌표 변환 및 위치 확인
- 다수의 조사지점 등록·선택·편집과 지도 마커 표시
- 현장 경로 및 조사 대상 위치 관리
- 현장사진 연결, 미리보기, 지점별 메모
- 건축HUB 업무정보 조회 및 결과 내보내기
- VWorld WMS/WFS 지도 레이어 검색·표시
- SHP, GPKG, DXF, KML, GeoJSON 등 GIS 데이터 확인
- 사업구간·버퍼·공간 교차·포함관계 분석 및 결과 레이어 관리
- 프로젝트 저장·재열기 및 CSV 등 업무자료 내보내기

일부 기능은 공공데이터 서비스의 제공 범위 및 사용자의 API 이용 권한에 따라 달라질 수 있습니다.

## 4. 실행조건
| 항목 | 조건 |
| --- | --- |
| 운영체제 | Windows 10 또는 Windows 11 |
| 시스템 | 64비트(x64) |
| 배포 형태 | 프로그램 전체 폴더를 포함한 ZIP(onedir) |
| 네트워크 | 온라인 지도·주소 검색·공공데이터 조회 시 필요 |
| 외부 서비스 | 해당 서비스에서 발급받은 API 키 또는 이용 권한이 필요할 수 있음 |
| Python 설치 | 완성된 실행형 패키지 사용에는 필요 없음 |

## 5. 실행 및 사용방법
1. 사용 권한에 따라 제공된 Sunrise Finder 배포 ZIP을 준비합니다.
2. ZIP의 프로그램 폴더 전체를 압축 해제하고 주 실행파일을 시작합니다.
3. 새 프로젝트를 만들거나 기존 프로젝트를 엽니다.
4. 주소·좌표를 검색하거나 GIS 파일을 불러옵니다.
5. 조사 지점을 지도에 등록하고 필요하면 경로·메모·사진을 연결합니다.
6. 건축·지도·공간 데이터를 조회한 뒤 사업구간과 버퍼 등의 분석을 진행합니다.
7. 프로젝트를 저장하고 필요한 결과를 내보냅니다.

프로그램 폴더 내부 파일을 일부만 따로 교체하지 말고, 제공된 완전한 패키지 단위로 사용하세요.
