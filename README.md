# Sunrise Finder

Sunrise Group의 현장조사·위치정보·GIS 데이터 통합 관리 프로그램입니다.

## 프로그램 목적

환경영향평가와 현장조사 업무에서 주소, 좌표, 지도, 공공데이터, 사진 및 공간분석 결과를 하나의 프로젝트로 연결하여 조사 자료의 수집·검토·관리를 지원합니다.

## 지원 운영체제

- Windows 10 / Windows 11 (64비트, x64)
- 온라인 지도·주소·공공데이터 조회 기능은 인터넷 연결과 해당 서비스의 이용 권한이 필요할 수 있습니다.

## 개발언어 및 주요 기술

- **개발언어:** Python
- **주요 기술:** GIS 공간데이터 처리, 지도 서비스·공공데이터 API 연동
- **배포 형태:** Windows 폴더형 실행 패키지(onedir)

## 주요 기능

- 도로명·지번주소 검색과 주소·좌표 변환
- 조사 지점 등록, 지도 표시, 경로 및 위치 관리
- 현장사진·메모와 조사지점 연결
- 건축HUB 및 VWorld WMS/WFS 등 공공·지도 데이터 조회
- SHP, GPKG, DXF, KML, GeoJSON 등 공간데이터 확인
- 사업구간, 버퍼 및 공간 교차·포함관계 분석
- 프로젝트 저장·재열기와 업무 데이터 내보내기
